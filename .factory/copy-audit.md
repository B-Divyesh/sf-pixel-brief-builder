# Landing page copy audit

Audited 2026-08-28 against the `plain-words` skill. Counts treat hyphenated terms and numbers as one word. UI labels and select choices are listed after the sentences. No sentence exceeds 22 words. No text contains a banned marketing word.

## First screen

| For an adult and child making a weekend game who need a small, shared drawing list. | 16 | Pass |
| Try it with sample data | 5 | Pass: primary action |
| Opens a finished 20-item packet. | 5 | Pass: states the result beside the action |
| Free to use. | 3 | Pass |
| Saves only in this browser. | 5 | Pass |
| Works offline after the first visit. | 6 | Pass |
| Start with the pieces your weekend can hold. | 8 | Pass |

Read aloud: “Plan your tiny game art first, for an adult and child making a weekend game. Try it with sample data.” The job and first action fit in one breath.

## Interface labels checked

Headings and actions are concrete: “Build the art packet,” “Pick four limits,” “Share one list,” “Finish the packet,” “Build my art packet,” “Export brief,” “Open printable packet,” and “Copy filenames.” Empty, error, offline, and demo states each name the next action. None contains a banned word.
